### Running with current PyTorch (what we found in the source; not executed, torch is not installed in the project venv)
1. `utils/loading_utils.py` calls `torch.load(path_to_model)` with no `map_location`; tensors are stored on `cuda:0`. On a CPU-only machine pass `map_location='cpu'`. On Kaggle GPU it loads as is.
2. PyTorch >= 2.6 defaults to `weights_only=True`. The pickles reference only the four globals above, which are tensor-rebuild types, so a weights-only load is expected to work; if it fails, `weights_only=False` is acceptable only because the file hash above is pinned. Must be confirmed in the first Kaggle cell (record torch version + success).
3. NumPy >= 1.24 removed `np.int`: used in `run_reconstruction.py` (line 43) and `utils/inference_utils.py` (lines 75, 457, 458, 462). Replace with `int` / `np.int64` in our vendored copy.
4. pandas >= 2.2 deprecates `delim_whitespace=True` (`run_reconstruction.py` line 42, `utils/event_readers.py` line 17): use `sep=r'\s+'`.
5. GPL-3.0: keep the attacker in a separate script under `experiments/` that downloads the upstream code at run time; do not copy GPL code into our (differently licensed) source tree without checking the repository license.
6. Practical plan for N3: write our own voxel-grid builder that matches `events_to_voxel_grid` (5 bins, bilinear in time, polarity +/-1), test it against the upstream function on a few windows, then load the two checkpoints into the upstream `E2VIDRecurrent` / `FireNet` classes.

## 3. What this means for the paper-2 experiments
- Threat-model wording should follow Du 2021: attacker knows the event format and uses public, pre-trained reconstruction (E2VID) and recognition networks. Ahmad 2023 and E2PRIV give the identity-leak metrics (SSIM/PSNR of reconstructions, face verification, re-ID rank-1).
- N3 (reconstruction attack): E2VID + FireNet, 5-bin voxel grid, same window as the dataset frames (~33 ms). Report SSIM/PSNR against reconstructions from plaintext events, per level V0-V4.
- N4 (learned attacker): justified by EV-Gait and EventFace (identity from raw events without reconstruction) and by AnonyNoise's attacker-fine-tuning stage; fine-tune FireNet (38k weights, cheap) on V1/V2 ciphertext with known plaintext.
- N9 (active attacks): neither Du 2021 nor Zhang 2024 has authentication (checked in their text); inject/replay/delete/splice will be accepted by both, whereas our per-packet Ascon tag rejects them. This is the clearest differentiator, together with the standard cipher (Zhang's key function rho is unspecified).
- Zhang 2024 is in Neuromorphic Computing and Engineering, the target journal: it must be cited and compared directly.
